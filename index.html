AI-Powered LinkedIn Content Automation

A self-hosted workflow that turns one topic into a complete, illustrated LinkedIn post with almost no manual effort.

n8n Gemini Google Sheets LinkedIn
End-to-end automated publishing
↗ Project details Self-hosted n8n
01 — Problem

From topic to published post

This self-hosted n8n workflow automates scheduled LinkedIn publishing. It retrieves a topic and audience type from Google Sheets, then turns them into a complete post, a matching AI-generated image, and a tracked publishing update.

02 — Workflow

A scheduled trigger starts the workflow. An LLM generates the copy and image prompt, an image-generation step creates the visual, and a Merge node combines both outputs. The finished post is published to LinkedIn and the sheet is updated with the result.

03 — Inputs & outputs

Inputs & outputs

  • Input: topic, audience type, prompts, and system prompt
  • Output: copy, image prompt, and generated image
  • Tracking: publishing status in Google Sheets
04 — Workflow

From topic to published post

Topic→ Prompt substitution→ Gemini copy + image prompt→ Image generation→ Merge→ Publish + track
05 — Workflow design

Why the stages are separated

Topic → copy + image → merged post → LinkedIn → status update

Observation: the workflow has distinct stages with explicit handoffs. Interpretation: each stage can be inspected and improved independently. Engineering implication: structured fields and a merge step keep the text and image synchronized before publishing.

06 — Node logic
  • Topic + system prompt → dynamic prompt fields — keeps each run reusable.
  • Raw Gemini response → structured post and image-prompt fields — makes downstream nodes predictable.
07 — Model development

Progression

Schedule trigger↓ Google Sheets↓ Code + Switch nodes↓ Gemini workflow

The workflow is evaluated by whether each handoff completes successfully: correct prompt replacement, structured AI output, image generation, merge completion, LinkedIn publishing, and status tracking.

08 — Evaluation

This is an automation project rather than a predictive model, so workflow reliability and successful end-to-end execution are more meaningful than classification metrics.

Success criteria: complete post + matching image + published status
09 — Error analysis
  • Failure points: malformed AI output, missing fields, or a failed publishing step.
  • Operational risk: a post should not publish until both the copy and image are available.
  • Next improvement: add stronger validation, retries, and human approval before publishing.
10 — Interpretability
Visible workflow stages make the automation explainable node by node.

The main design choice is decomposition: prompting, parsing, image generation, merging, publishing, and tracking are separate stages rather than one opaque AI call.

11 — Business impact

The workflow reduces repetitive content-production work and creates a traceable publishing process. It also provides a foundation for extending the same pattern to platforms such as Medium or Slack.

12 — Deployment

Deployed prototype · self-hosted workflow

Google Sheets↓ n8n↓ Gemini↓ LinkedIn↓ Status update
13 — Reproducibility
Self-hosted n8n Google Sheets Gemini LinkedIn publishing

Computer Vision

Signature Verification Model

Classify genuine and forged signatures using image preprocessing and a convolutional neural network.

Python TensorFlow CNN
~70% accuracy
↗ Project details
01 — Problem

Signature authentication is an image-classification problem where the model must distinguish genuine handwriting patterns from forged examples.

02 — Dataset
  • Data: genuine and forged PNG signature images
  • Preprocessing: grayscale resize to 128 × 128
  • Split: 80% training, 20% test
03 — Approach

Used a TensorFlow CNN with two convolution and max-pooling stages, followed by dense layers and dropout. Training ran for 30 epochs with Adam and binary cross-entropy.

04 — Evaluation & result

The model achieved 70% test accuracy. A small Tkinter interface was also created so a user can enter an ID, upload a signature image, and receive a genuine or forged prediction with confidence.

05 — Business impact

The project demonstrates an applied deep-learning workflow for document and identity-verification use cases.

Movie Recommendation Model

Recommend similar movies by learning content relationships from movie descriptions and metadata.

Python Bag-of-Words Vectorization
Content-based recommendations
↗ Project details
01 — Problem

The project creates personalized movie suggestions without requiring user-rating history, using content similarity instead.

02 — Dataset
  • Dataset: TMDB 5,000 movies + credits
  • Cleaning: merged tables, parsed metadata, removed nulls and duplicates
  • Output: top-10 similar-movie recommendations
03 — Approach

Combined genres, keywords, overview, cast, and crew into a text representation. Applied stemming with NLTK, CountVectorizer from scikit-learn, and cosine similarity to rank related movies.

04 — Evaluation & result

The system returns relevant titles for inputs such as “Batman,” “Iron Man,” and “Hitman.” It uses content relationships rather than collaborative user history, making the recommendation logic easier to inspect.

FinTech · Classification

Credit Card Fraud Detection Model

Detect fraudulent transactions with class-imbalance handling and ensemble learning.

Logistic Regression Random Forest XGBoost SMOTE
F1 0.71 → 0.86
↗ Project details
01 — Problem & data

Built a fraud-detection system on 284,807 credit-card transactions with 30 numeric features and a highly imbalanced fraud label. The goal was to identify fraudulent activity while controlling false positives.

02 — Approach

Performed null checks, exploratory analysis, correlation analysis, standard scaling, and a stratified 75/25 train-test split. Compared Logistic Regression, Random Forest, and XGBoost, with SMOTE used to address class imbalance.

03 — Evaluation

Used precision, recall, and F1-score because missing fraud and incorrectly flagging legitimate transactions have different costs.

04 — Result & impact

F1-score improved from 0.71 with Logistic Regression to 0.86 with the strongest ensemble result. The project also reported a 20% reduction in fraudulent transactions, 15% fewer false positives, and 20% fewer false negatives.
